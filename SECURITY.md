# Security Policy

## Supported Versions

This project is currently in active development. Only the latest major version receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please email me directly at kurr7809@gmail.com with details.

I will review the report as soon as possible and aim to respond within 3–5 business days. If the vulnerability is confirmed, I will work on a patch and notify users in the GitHub release notes.
